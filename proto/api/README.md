# clusdr API

Application gRPC for the clusdr daemon: health, membership, watch, events, locks, and leases.

- BSR: [`buf.build/clusdr/api`](https://buf.build/clusdr/api)
- Package: `clusdr.v1alpha1`

Language SDKs export this module. Node-to-node join and heartbeat live in [`buf.build/clusdr/internal`](https://buf.build/clusdr/internal).
