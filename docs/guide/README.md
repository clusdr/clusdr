# Tutorial

Take a laptop from zero to a local cluster and one SDK call. Read **in order**. Each page leaves a process you use on the next page.

1. [Install the binary](install.md) — `clusdr` on `PATH`
2. [Start the first member](first-member.md) — identity, Raft, one row in `members`
3. [Grow the cluster](grow.md) — a second voter, then an observer
4. [Watch and publish](watch.md) — the stream, then one signal
5. [Use it from your app](from-your-app.md) — `Local()` / `local()`

Checkpoint at the end of each page before you continue.

When you need a real NIC, a container, or Kubernetes, leave the tutorial: [How-to](other-hosts.md). Guarantees: [Concepts](../concepts/). A flag: [Reference](../reference/).
