# Documentation

clusdr docs teach the host-daemon model in order (guide), then let you look up a flag or RPC (reference) or pin down a guarantee (concepts). If you landed here from the repository, start at [Get started](./README.md) — install the binary, run one member, then grow the cluster.

| Section | When to open it |
|---|---|
| [Get started](./README.md) | First install and first cluster |
| [Guide](guide/) | Tutorials and how-to pages |
| [Concepts](concepts/) | Why membership, presence, locks, and Kubernetes look the way they do |
| [Reference](reference/) | CLI, gRPC API, configuration, errors |
| [SDKs](sdk/) | Language walkthroughs after [from your app](guide/from-your-app.md) |
| [Glossary](glossary.md) | One-line definitions used everywhere else |

Do not start from a CLI flag or a YAML key. The guide establishes context; reference is lookup after that.
